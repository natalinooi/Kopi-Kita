## 🚀 Cara Melihat Prototype

1. **Dashboard Visual**: Buka file [index.html](file:///D:/.%20Pelajaran/KK/KIK/APK%20dari%20Prototipe/index.html) langsung di browser Anda untuk melihat galeri visual interaktif semua screen beserta tautan live code.
2. **Preview Individual Screen**: Buka file HTML atau SVG yang berada di folder `code/` atau masing-masing folder modul di dalam `screens/`.
3. **Penyusunan APK**: File HTML dan SVG yang diunduh sudah siap dikonversikan menjadi APK mobile (menggunakan WebView, Capacitor, Apache Cordova, atau Flutter WebView).
